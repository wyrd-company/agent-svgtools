# Demo Targets

These public-domain raster images are kept as reusable targets for exercising
the SVG reconstruction workflow. They are intentionally not expected to trace
perfectly; they are useful because an agent can run `colors`, `trace`, and
`judge`, then practice improving a clean SVG by component.
