# Demo Targets

These public-domain raster images are kept as reusable targets for exercising
the SVG reconstruction workflow. They are intentionally not expected to trace
perfectly; they are useful because an agent can inspect the raster with
`colors`, reconstruct semantic components, audit the SVG with `inspect`, and
iterate with foreground-scoped `judge` artifacts. `trace` is reserved for
disposable diagnostics rather than final geometry.
